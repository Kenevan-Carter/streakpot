## Decision 001 — Use Supabase for the Database

**Date:** August 12, 2026  

### Decision

Use Supabase as the backend database and authentication provider.

### Why

Supabase provides PostgreSQL, authentication, row-level security, and an API that works well with the React frontend.

It also avoids needing to manage a PostgreSQL server locally.

I also ran into trouble being able to support my owwn database on my system since my Mac is out of date.

### Alternatives Considered

- Local PostgreSQL
- Firebase
- Custom Express/PostgreSQL backend

### Consequences

**Pros**
- Easier authentication
- Hosted PostgreSQL database
- Built-in RLS security
- Easy React integration

**Cons**
- Application becomes somewhat dependent on Supabase
- Need to learn Supabase-specific authentication and security features

## Decision 002 — Identify Users by Supabase User ID

**Date:** August 12, 2026  

### Decision

Use the UUID generated by Supabase Auth as the primary identifier for users throughout the database.


### Why

Usernames may change and emails may change.

Supabase user IDs are unique and remain associated with the account.

## Decision 003 - database tables
### Decision
Chose the following tables for the database:
1. profiles - WHO the user is
2. contests -  what contests they are entering
3. games - stores individual games and their results
4. contest_entries -  who entered what contest
5. picks - each users individual picks

1. profiles — user information like username, display name, avatar, and account creation date.
2. contests — contest information like sport, contest name, entry fee, status, start time, and close time.
3. games — matchup information like away team, home team, league, game time, status, and winner.
4. contest_entries — which users entered which contests and when they entered.
5. picks — which team each user picked for each game, whether that pick was correct.


### Why
Supabase has all relational databases so by storing ids, they can talk to eachother and make it easier to access sahy a users picks from just their user id.
